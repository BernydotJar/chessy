# Chessy Design System v2 - Product research

Date: 2026-09-06

## Research synthesis

The redesign follows five product observations from current chess and learning products:

1. Chess players reward speed, directness and board clarity. Recent Lichess app feedback repeatedly praises a clean, smooth, minimal interface and better touch controls.
2. Players react negatively when home screens become cluttered or basic analysis is buried behind multiple navigation steps.
3. Board, piece and background customization are expected capabilities in mature chess products; themes are not decoration-only.
4. Beginners value structured lessons, approachable terminology and coach-like guidance, while stronger players expect serious analysis, puzzles and PGN workflows.
5. Habit mechanics work when they make progress legible: streaks, XP and milestone celebration should support learning rather than dominate the interface.

## Product principles

- Board first: the board remains the highest-contrast visual object in play/training contexts.
- Quiet chrome: navigation and surfaces use restrained elevation and one accent at a time.
- One-click learning: Challenge, Academy, Analysis and Review remain directly reachable.
- Structured progression: progress is visible through meaningful completion, not decorative gamification.
- Theme as preference: a theme changes UI tokens and board palette together and persists locally.
- Custom icon language: primary product/navigation icons use Chessy-owned SVG geometry; Lucide remains acceptable for secondary low-brand utilities.
- Mobile is a first-class surface: bottom navigation gives thumb-access to the five highest-frequency destinations.
- No AI-slop patterns: avoid excessive glow, unrelated gradients, arbitrary rounded cards, purple/amber accents without semantic meaning, and decorative copy that competes with tasks.
