# Design
React/Vite + livekit-client, custom accessible controls matching Chessy. Firebase callable Functions v2 authorize all media lifecycle and moderation. Firestore live/current is the private observable class summary, learningRoomLiveSessions/{id} is server-only lifecycle/credential state.
Persistent learning room and temporary class session are separate. At most one starting/live/closing session per room. A transaction links room, session, and summary. Join writes a credential ledger in a transaction reading the room/session/membership, then signs and revalidates. Close changes session to closing before any provider operation; queries the complete credential ledger; explicit token cutoff, then DeleteRoom. Banned identities remain denied on new token requests.
Production uses LiveKit Cloud for explicit token revocation; ws://loopback is permitted only under the Firebase emulator with an explicit QA mode. Secrets bind only media endpoints and reconciliation. Class duration is at most 120 minutes, capacity 12 participants. Credentials expire in 90 seconds; refreshed credentials are revoked by explicit timestamp. Scheduler runs every minute and never ACKs incomplete revocation.
No raw JWTs or provider secrets enter logs/evidence/Git. Disposable provider QA uses a unique chessy_ room prefix and performs cleanup. Existing provider account may be shared for QA; Chessy production needs its own configured scope.
Graph: a new increment graph uses the existing shared harness pinned at 168b740045293089720964bdc0d2bda79828b5c8, with a dedicated thin adapter. Historical premium graph/pin/events are preserved unchanged. No engine implementation is copied.
